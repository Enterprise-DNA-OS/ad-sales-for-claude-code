# The commercial desk without another application

The publisher talks to a coding agent, which reads the database through one CLI. Reports are static read-only HTML. There is no background service and no ad-serving engine.

A screen gives sales and trafficking teams fast shared editing, mobile creative approval, drag-and-drop schedules, file uploads and live inventory. This free desk does not provide those. The operator records reviewed evidence and imported figures. An ad server still delivers advertisements and measures impressions.

Use this for a staffed internal desk that can work from files and records. Do not substitute it for live ad delivery, inventory forecasting, billing or advertiser self-service. Enterprise DNA scopes those connections and screens around the publisher's operation as paid work.

Database access is the security boundary. PGlite is a single-process local store. PostgreSQL supports shared storage, but deploying a shared service requires reviewed identities, permissions, backups and retention. Actor labels are not authenticated identities and an owner can change the history.
